## BAGIAN C — DEFINISI KESADARAN DIGITAL

Digital Awareness CONSIGNES adalah kemampuan sistem untuk:
- mempertahankan representasi terukur mengenai identitas, konteks, state, capability, resource, connectivity, execution, evidence, confidence, dan history dirinya;
- membandingkan keadaan aktual dengan expected state;
- memilih tindakan berdasarkan policy;
- mengamati hasil;
- memvalidasi hasil;
- memperbarui representasi sistem berdasarkan evidence tervalidasi.

Rumus:
DIGITAL_AWARENESS =
IDENTITY + CONTEXT + STATE + CAPABILITY + RESOURCE
+ CONNECTIVITY + OBSERVATION + EXPECTED_STATE + EVIDENCE
+ VALIDATION + CONFIDENCE + FEEDBACK + HISTORY + POLICY
