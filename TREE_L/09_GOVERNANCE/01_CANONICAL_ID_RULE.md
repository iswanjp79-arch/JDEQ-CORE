# CANONICAL ID RULE

## Tujuan
Memisahkan identitas mesin dari label manusia.

## Pola
HUMAN_LABEL : IK-006  P3K
MACHINE_ID  : 03.06.01

## Aturan
- Machine ID wajib deterministik, hierarkis, dan stabil.
- Machine ID tidak boleh berubah karena perubahan istilah manusia.
- Label manusia boleh berubah asal tidak menghapus machine ID.
- Setiap node/agent/capability/task/evidence menggunakan pola yang sama.
