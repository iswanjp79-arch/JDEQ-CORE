# DIRECTION MANIFEST — MICO-JDEQ

## Prinsip Utama
- Manusia (L0) adalah pencipta dan pemegang kedaulatan.
- Mesin AI dan Cloud hanyalah alat bantu.
- PC-i5 adalah laboratorium R&D lokal, bukan pabrik komersial.
- Infinix 32-bit : Field Evidence / Pre-processing ringan (input dari lapangan, foto, catatan)
- Vivo Y28 : Thin Client / Remote Control (layar kendali, bukan pemroses berat)
- HP-Mini : Utility / Relay / Recovery ringan
- Aspire One : Lightweight Observer / Recovery / Cold Backup
- Cloud hanya pekerja kasar opsional, tidak menyimpan inti.

## Model Kerja
- Z83 = traffic controller / mandor.
- PC-i5 = heavy worker lokal.
- Vivo Y28 = thin client / remote control.
- Infinix = field evidence & pre-processing ringan.
- HP-Mini = relay & utility cadangan.
- Aspire One = observer & recovery ringan.
- Cloud = eksekutor tugas besar sementara.

## Strategi Pendapatan
- API Arbitrage: manfaatkan token gratis/murah untuk layanan AI.
- Jual sistem/workflow, bukan jual hardware.
- Gunakan open-source & script sederhana sebanyak mungkin.

## Visi Phase 3+ (Tidak Dieksekusi Sekarang)
- Distributed Edge Cluster: menggabungkan perangkat kecil sebagai satu pipa produksi.
- Wake-on-LAN untuk efisiensi energi.
- Menunggu fondasi stabil dan BAST disahkan.
