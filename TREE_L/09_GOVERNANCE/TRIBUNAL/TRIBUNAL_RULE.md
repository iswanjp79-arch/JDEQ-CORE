# TRIBUNAL RULE — Protokol Orkestrasi 653 Agen

## Prinsip
- Tribunal adalah wadah resmi untuk menampung suara 653 agen.
- Jarvis bertindak sebagai Check Valve dan Panglima Lapis Pertama.
- DeepSeek hanya bertugas sebagai eksekutor teknis sesuai Task Card.

## Alur
1. Semua jawaban masuk ke INBOX.
2. Jarvis membaca, menyaring, dan memisahkan noise.
3. Hasil matang disimpan ke FILTERED.
4. Hanya 1 paragraf kesimpulan yang disetorkan ke L0.

## Aturan Mutlak
- Tidak ada jawaban mentah yang langsung masuk ke L0.
- Semua file INBOX harus berformat JSON atau teks pendek.
- Setiap file FILTERED harus memiliki SHA256.
- Folder ini tidak boleh diubah tanpa ACC L0.
- Tidak ada proses otomatis yang berjalan terus-menerus tanpa izin.
