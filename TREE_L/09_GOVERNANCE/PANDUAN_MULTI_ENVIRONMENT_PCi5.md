# PANDUAN MULTI-ENVIRONMENT — PC-i5

## Lingkungan
- PowerShell : tugas Windows utama.
- CMD        : fallback jika PowerShell tidak tersedia.
- WSL2       : Linux tools, Python, Git, remote access.
- Ubuntu     : sama dengan WSL2, untuk kerja CLI/DEB.

## Aturan
- Script PowerShell boleh mengelola OS/folder.
- Python digunakan untuk pemrosesan data/AI.
- JSON adalah format komunikasi antar agen.
- Jangan campur peran; biar setiap alat fokus.

## Catatan Khusus
- Jangan install WSL2/Ubuntu jika belum ada; itu bukan kebutuhan fase ini.
- Semua perubahan di Windows harus melalui Task Card.
