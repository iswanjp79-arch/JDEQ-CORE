# TASK CARD CONTRACT (DRAFT)

## Tujuan
Standar minimal untuk setiap Task Card sebelum dieksekusi.

## Field Wajib
- task_id
- judul
- fase
- target_node
- objective
- scope
- exclusions
- resource_budget
- risks
- evidence_required
- acceptance_criteria
- rollback_method
- approval_status

## Status Transisi
DRAFT  REVIEW  APPROVED  EXECUTING  VERIFYING  DONE
Alternatif: BLOCKED / FAILED / ROLLBACK_REQUIRED
