# KANBAN RULE  File-Based Workflow

## Prinsip
- Kanban cukup pakai folder, tanpa aplikasi tambahan.
- Setiap Task Card adalah file Markdown.
- Status dipindahkan antar folder TODO / DOING / DONE.

## Alur
1. Tugas baru masuk ke TODO.
2. Saat dikerjakan, pindah ke DOING.
3. Setelah selesai, pindah ke DONE.
4. Bukti wajib disimpan di 08_EVIDENCE.

## Larangan
- Dilarang menyimpan data di luar folder ini.
- Dilarang menghapus Task Card dari DONE tanpa ACC L0.
- Dilarang memakai database/server untuk Kanban.
