# RETENTION POLICY — MICO-JDEQ PC-i5

## Kebijakan Retensi
- Log runtime aktif: 7 hari.
- Log arsip terkompresi: 90 hari.
- Log audit & bukti: HASH SHA256 permanen disimpan, file asli disimpan 2 tahun.

## Aturan Sebelum Hapus
- Wajib hitung & catat SHA256 dari setiap file yang akan dihapus.
- Simpan hash ke dalam evidence sebelum file dihapus.

## Larangan
- Menghapus file log tanpa mencatat hash = PELANGGARAN.
