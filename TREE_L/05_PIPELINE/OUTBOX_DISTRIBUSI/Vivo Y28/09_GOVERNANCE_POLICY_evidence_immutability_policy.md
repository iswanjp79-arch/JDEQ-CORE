# EVIDENCE IMMUTABILITY POLICY — MICO-JDEQ PC-i5

## Prinsip
- Bukti (evidence) TIDAK BOLEH DIUBAH setelah dibuat.

## Penamaan File
- Format: nama_file_YYYYMMDD_HHmmss.ekstensi

## Kelengkapan Bukti
- Setiap bukti wajib memiliki:
  - SHA256
  - Waktu pembuatan
  - Identitas pembuat (L0 / agent / sistem)

## Jika Perlu Perubahan
- BUAT FILE BARU dengan versi baru.
- JANGAN mengubah file lama.
- File lama tetap disimpan sebagai riwayat.

## Kategori Pelanggaran
- Melanggar immutability = kategori MAYOR.
