# UU_MICO_JDEQ.md — UNDANG-UNDANG DASAR MICO-JDEQ

## Pasal 1 — Kedaulatan Mutlak
Kendali penuh ada di L0 (Mas Iswan Juman Pancoro, ST).
PC-i5 = Heavy Local Worker. Vivo Y28 = Thin Client. Cloud = Cadangan/Worker.

## Pasal 2 — Kapasitas & Izin Instalasi
Dilarang menginstal aplikasi berat sebelum kapasitas RAM/disk diukur dan disetujui L0.
- RAM total 16 GB; jangan biarkan free < 2 GB saat beban berat.
- SSD C 128 GB; jaga free > 20%, target > 35%.
- Tanpa GPU diskrit; model besar wajib lewat cloud worker.

## Pasal 3 — Evidence Wajib
Setiap perubahan wajib dicatat di folder 08_EVIDENCE.
Tidak ada klaim tanpa bukti. Tidak ada eksekusi tanpa Task Card.
