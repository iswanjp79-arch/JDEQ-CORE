## 1. TUJUAN
Menerapkan fondasi 7 Lapisan OSI ke seluruh ekosistem MICO-JDEQ.
Setiap perangkat menjalankan L1-L7 lengkap dan mandiri.
Penyatuan hanya di L7: MICO-JDEQ CONSIGNES AWARENESS.
Bukan replikasi organisme - kesadaran digital berbasis data teratur.

## 2. PRINSIP
- Sistem terintegrasi, beda tugas disambung jadi satu.
- Satu perangkat = satu tumpukan 7 lapisan lengkap.
- Mandiri di bawah, menyatu di atas (L7).

## 3. PETA 7 LAPISAN
| Layer | Nama | Fungsi Inti |
|---|---|---|
| L1 | Fisik | CPU/NPU, RAM, storage, daya, antarmuka |
| L2 | Jaringan | IP, socket, WiFi, protokol |
| L3 | Inti/OS | Kernel, manajemen HW, penjadwalan |
| L4 | Perantara | Daemon, buffer, layanan latar |
| L5 | Aturan & Peran | Governance, hak akses, SOP |
| L6 | Kognitif | LLM lokal, analisis, pembelajaran pola |
| L7 | Aplikasi & Komando | UI, penyatuan perintah, kesadaran terpadu |

## 5. JARINGAN
- WiFi Lokal Domain Privat - sambungan utama
- IndiHome - pintu keluar/masuk cloud
- IP Lokal - komunikasi tanpa internet publik
- Protokol - HTTP/HTTPS, SSH, MQTT, gRPC

Alur data:
Sensor -> tepi -> penyangga -> pengolah -> penyimpan -> cadangan awan.
Setiap langkah dicatat, tidak diubah.
