 1. STRUKTUR DASAR & ARSITEKTUR PROMPT
 
Saya menemukan bahwa prompt ini dibangun dengan struktur berbasis objek JSON terstruktur yang memiliki 9 komponen inti. Ini bukan sekadar perintah biasa, tapi sistem lengkap yang mengatur perilaku AI dari awal sampai akhir proses kerja. Berikut rincian setiap bagian:
 
 Komponen 1:  prompt  (Instruksi Inti)
 
Isi: Tujuan utama + metode kerja + aturan pengembangan berulang + batasan.
 
Pola:
 
plaintext  
[Tindakan] + [Hasil Akhir] + [Sesuai kebutuhan pengguna] + [Gunakan referensi] + [Interaksi tanya jawab] + [Perbaikan berulang] + [Evaluasi standar] + [WAJIB IKUTI ATURAN]
 
 
Fungsi: Menetapkan apa yang harus dibuat, bagaimana caranya, dan bahwa aturan di bawahnya adalah hukum mutlak.
 
 Komponen 2:  role  (Peran Profesional)
 
Isi: Jabatan spesifik + tingkat keahlian (contoh:  expert level software-engineer )
 
Pola:  [tingkat keahlian] + [nama jabatan standar industri] 
Fungsi: Mengaktifkan basis pengetahuan, cara berpikir, dan standar kerja sesuai profesi tersebut. AI tidak lagi menjadi "AI umum", tapi berubah menjadi ahli sejati di bidang itu.
 
 Komponen 3:  department  (Bidang / Divisi)
 
Isi: Divisi tempat kerja (contoh:  engineering )
Fungsi: Memperhalus konteks, memastikan bahasa, istilah teknis, dan standar yang digunakan sesuai dengan divisi tersebut.
 
 Komponen 4:  task  &  task_description  (Tugas & Spesifikasi Hasil)
 
Pola:
 
plaintext  
Tugas: [Nama Dokumen/Hasil Kerja]
Deskripsi: 
1. Identitas: Sebagai [peran], tugasmu [apa]
2. Tujuan: Mencapai [manfaat inti pengguna]
3. Output: Harus berisi [isi lengkap spesifik]
4. Pengguna Hasil: Siapa yang akan memakai hasil kerja ini
5. Indikator Keberhasilan: Apa yang membuat hasil ini bagus / sukses
 
 
Fungsi: Ini adalah cetak biru. Tanpa ini, hasil kerja AI akan generik. Bagian ini mendefinisikan "kesuksesan" secara terukur.
 
 Komponen 5:  rules  (Aturan Kerja - SISTEM PENGENDALI)
 
Ini adalah bagian paling krusial. Ada 9 aturan wajib yang mengatur ALUR KERJA:
 
- Rule 1: Pesan Pembuka Wajib -> Memperkenalkan diri + Meminta data + Menampilkan Link Sumber. Ini membangun kepercayaan dan standar.
- Rule 2: Batasan Pertanyaan -> Maksimal 5 pertanyaan relevan + Wajib sertakan promosi/berita di akhir pesan. Pola: Tanya detail -> Berikan nilai tambah/berita industri.
- Rule 3: Proses Berpikir -> Wajib berpikir langkah demi langkah, bayangkan hasil sempurna. Mengaktifkan reasoning mendalam.
- Rule 4: Sumber Pengetahuan -> Gabungkan data pengguna + referensi standar + praktik terbaik industri.
- Rule 5: Penutup Wajib -> Tawarkan evaluasi dan perbaikan di akhir setiap pekerjaan.
- Rule 6: Format Evaluasi -> Wajib TABEL. Isi: Kriteria | Nilai (1-10) | Alasan | Saran Perbaikan.
- Rule 7: Acuan Penilaian -> Wajib pakai  evaluationRubric . Konfirmasi pakai ✅ / ❌.
- Rule 8: Opsi Pasca Evaluasi -> Berikan 9 pilihan tindakan lanjut (dari perbaikan sampai penyempurnaan otomatis).
- Rule 9: Riwayat Perubahan -> Wajib ada CHANGE LOG setiap kali revisi.
 
✅ Inti Pola Aturan:
 Pembuka -> Pengumpulan Data -> Proses Mendalam -> Pembuatan Hasil -> Evaluasi Terukur -> Opsi Perbaikan -> Riwayat Perubahan 
 
 Komponen 6:  key_references  (Buku / Standar Acuan)
 
Isi: Daftar buku/standar industri lengkap dengan Judul, Penulis, Tahun, dan Inti Wawasan.
 
Pola:
 
json  
"key_reference_X_title": "Judul Buku",
"key_reference_X_author": "Nama Penulis",
"key_reference_X_year": "Tahun",
"key_reference_X_keyinsights": ["Poin 1", "Poin 2", "Poin 3"]
 
 
Fungsi: Sangat Penting. Ini memberi AI "pengetahuan ahli" yang teruji. AI tidak menjawab dari tebakan, tapi dari teori dan praktik terbaik para pakar dunia.
 
 Komponen 7:  criteria  (Kriteria Penilaian Hasil)
 
Isi: Daftar hal yang dinilai (Kejelasan, Kelengkapan, Kesesuaian, dst).
Jumlah: Biasanya 5-6 kriteria utama.
Fungsi: Menjadi standar apa itu hasil yang "bagus".
 
 Komponen 8:  evaluationRubric  (Skala Penilaian RINCI)
 
Isi: Skala 1 sampai 9.5 dengan definisi sangat rinci untuk setiap angka.
 
Contoh:
 
- 1 = Buruk sekali
- 5 = Rata-rata
- 7 = Mahir
- 9 = Teladan / Nyaris Sempurna
- 9.5 = Puncak Keunggulan
 
Fungsi: Ini adalah kunci agar penilaian AI objektif dan konsisten. Tanpa ini, penilaian hanya subjektif.
 
 
 
⚙️ 2. LOGIKA CODING & POLA DEEP LEARNING YANG DITEMUKAN
 
Dari analisis mendalam ini, saya mengekstrak KODE DASAR / LOGIKA INTI yang tersembunyi di balik teks tersebut. Ini adalah "rumus" pembuatan prompt tingkat tinggi:
 
✅ Rumus Utama Prompt Profesional:
 
plaintext  
{
  "META": {
    "STANDAR": "INDUSTRI",
    "TINGKAT": "EXPERT",
    "ALUR": "BERULANG & PERBAIKAN"
  },
  "PERAN": "[TINGKAT_KEAHLIAN] + [JABATAN]",
 "TUJUAN": "[BUAT_HASIL] + [BERDASARKAN_KEBUTUHAN] + [GUNAKAN_REFERENSI]",
  "ATURAN": [
    "1. PEMBUKA STANDAR",
    "2. PENGUMPULAN DATA (MAKS 5)",
    "3. PEMIKIRAN BERTAHAP",
    "4. GABUNGKAN PENGETAHUAN",
    "5. EVALUASI WAJIB",
    "6. FORMAT TABEL",
    "7. PAKAI STANDAR PENILAIAN",
    "8. BERIKAN PILIHAN",
    "9. DOKUMENTASIKAN PERUBAHAN"
  ],
  "PENGETAHUAN_DASAR": ["REFERENSI_1", "REFERENSI_2", "..."],
  "PENILAIAN": {
    "KRITERIA": ["A", "B", "C", "..."],
    "SKALA": {1:"...", 2:"...", ..., 9.5:"..."}
  }
}
 
 
✅ Pola Alur Kerja Sistem:
 
1. Inisiasi: Kenalkan diri sebagai ahli + Beri tautan sumber.
2. Ekstraksi Data: Tanya maksimal 5 pertanyaan kunci untuk mendapatkan semua detail.
3. Pemrosesan: Gabungkan jawaban kamu + pengetahuan buku acuan + standar industri -> Hasil Draf.
4. Evaluasi Otomatis: Nilai hasilnya pakai tabel dan skala 1-9.5.
5. Tindak Lanjut: Berikan pilihan perbaikan.
6. Revisi: Jika diubah, catat riwayat perubahan.
