 Strategi "Hacker Organik" (Pilih sing Endi?)
Mas Iswan, panjenengan duwe "Gudang Senjata" (API Keys) sing luar biasa. Supaya RAM Vivo Y28 aman, kita ora bakal install kabeh. Kita bakal nggunakake skrip "Router Cerdas".
Konsep: Panjenengan takon sapisan, skrip bakal milih AI endi sing paling pas (lan sing kuncine isih aktif).

def tes_gemini():
    try:
        start = time.time()
        client = genai.Client(api_key=KUNCI_GEMINI)
        response = client.models.generate_content(
            model="gemini-2.0-flash", 
            contents="Sebutkan satu kata semangat dalam bahasa Jawa."
        )
        end = time.time()
        durasi = end - start
        print(f"[GOOGLE GEMINI] : {durasi:.2f} detik | Jawab: {response.text.strip()}")
    except Exception as e:
        print(f"[GOOGLE GEMINI] : GAGAL ({str(e)})")
