3. PUSAT AI (LOKAL + CLOUD + KUANTUM)
Mosquitto MQTT + Ollama + Azure Functions + IBM Quantum Experience
- AI Lokal:
- Pasang Mosquitto MQTT Server (gratis) di laptop Travelmate → jalankan sebagai layanan lokal.
- Laptop: Pasang Ollama (gratis) → jalankan model Llama 3 8B → hubungkan ke Mosquitto dengan script Python sederhana:
python
import paho.mqtt.client as mqtt
import ollama
client = mqtt.Client()
client.connect("localhost", 1883, 60)
def on_message(client, userdata, msg):
    prompt = msg.payload.decode()
    response = ollama.chat(model='llama3', messages=[{'role': 'user', 'content': prompt}])
    client.publish("ai/laptop/response", response['message']['content'])
client.subscribe("ai/command")
client.on_message = on_message
client.loop_forever()
 
- Ponsel Android: Pasang Local AI Runner (gratis Play Store) → setting MQTT broker dengan alamat IP laptop kamu.
- Ponsel iOS: Pasang MLX Chat (gratis App Store) → hubungkan ke MQTT via aplikasi MQTTool (gratis).
- AI Cloud:
