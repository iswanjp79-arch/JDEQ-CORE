Aturan: Fungsi BERBEDA, bukan alternatif. Pola: 10 Kategori → 5 Utama → 3 Inti → 1 Paling Penting per kategori
 1. PEMROSESAN & MANIPULASI DATA (10)
✅ Inti
1. Pandas – Tabel/dataframe, transformasi, pembersihan data
- Kelebihan: Sangat lengkap, banyak fungsi, standar industri
- Kekurangan: Berat di data besar, memori boros
- Performa: Sedang → Lambat (>1M baris); mudah dipakai
2. Polars – Alternatif cepat, berbasis Rust, evaluasi malas
- Kelebihan: 5–10x lebih cepat, hemat memori, API mirip Pandas
- Kekurangan: Fitur belum selengkap Pandas
- Performa: Sangat tinggi; terbaik untuk data besar
3. NumPy – Dasar hitung angka, matriks, vektor
- Kelebihan: Dasar semua pustaka, sangat cepat, efisien
- Kekurangan: Hanya angka, bukan tabel
- Performa: Maksimal (C-level); pondasi utama
⚡ Pendukung
4. Dask → Data besar melebihi memori, paralel → Performa: Tinggi, skalabel
5. Vaex → Dataframe luar memori, cepat → Performa: Sangat tinggi
6. PyArrow → Format data cepat, pertukaran antar sistem → Performa: Maksimal
7. SciPy → Hitung ilmiah: aljabar, statistik, sinyal → Performa: Tinggi
8. Pandera → Validasi struktur dataframe → Performa: Sedang
9. Fugue → Menjalankan Pandas/Spark/Dask satu kode → Performa: Menengah
10. Datatable → Cepat baca/tulis CSV besar → Performa: Sangat tinggi

 3. KOMUNIKASI ANTAR SISTEM / RPC / JARINGAN (10)
✅ Inti
1. grpcio → RPC cepat, HTTP/2, biner, lintas bahasa 
- Kelebihan: Sangat cepat, biner, aman, standar Google

- Performa: Sangat tinggi; tercepat antrean ringan
⚡ Pendukung
4. aiohttp → HTTP asinkron, klien+server → Performa: Sangat tinggi
5. Requests → HTTP sinkron standar → Performa: Sedang; paling mudah
6. JSONRPC → RPC berbasis JSON, mudah dibaca → Performa: Menengah
