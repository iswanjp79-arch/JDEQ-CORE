 aku ngertinya ginian : localhost.run — sebuah layanan tunneling berbasis SSH yang sudah tersedia di Termux.
Cara kerjanya:
1. Flask server berjalan di Termux pada port 5000.
2. SSH tunnel localhost.run memberi Anda URL publik (contoh: https://xxxxx.localhost.run) yang bisa diakses dari mana saja.
3. Semua API key tetap aman di vault lokal.
---
 BUNDEL TERIMA BERES — MICO SERVER + TUNNEL PUBLIK
Tempelkan seluruh blok ini di Termux (di folder ~/JDEQ).
Jika ada error, laporkan outputnya. Saya akan perbaiki.

cat > api/mico_server.py << 'FLASK'
from flask import Flask, request, jsonify
import json, os, subprocess
app = Flask(__name__)
INVENTORY_FILE = os.path.expanduser("~/JDEQ/catatan/agent_inventory.txt")
VAULT_DIR = os.path.expanduser("~/JDEQ/vault/keys")
LOG_FILE = os.path.expanduser("~/JDEQ/logs/server.log")
def log(msg):
    with open(LOG_FILE, "a") as f:
        f.write(f"[{__import__('datetime').datetime.now()}] {msg}\n")
@app.route("/")
def home():
    return jsonify({"status": "MICO Server Active", "agents": "653", "mode": "localhost.run tunnel"})
@app.route("/showcase")
def showcase():
    agents = []
    if os.path.exists(INVENTORY_FILE):
        with open(INVENTORY_FILE) as f:
            for line in f:
                id_name = line.strip().split(":")
                agents.append({"id": id_name[0], "name": id_name[1]})
    return jsonify({"total": len(agents), "agents": agents})
@app.route("/vend", methods=["POST"])
def vend():
    data = request.json
    agent = data.get("agent", "deepseek")
    prompt = data.get("prompt", "Hello")
    key_file = os.path.join(VAULT_DIR, f"{agent.lower()}.keys")
    if not os.path.exists(key_file):
        return jsonify({"error": f"Key for {agent} not found"}), 404
    with open(key_file) as f:
        api_key = f.read().strip()
    # Panggil API DeepSeek
    if agent.lower() == "deepseek":
        result = subprocess.run([
            "curl", "-s", "https://api.deepseek.com/v1/chat/completions",
            "-H", f"Authorization: Bearer {api_key}",
            "-H", "Content-Type: application/json",
            "-d", f'{{"model":"deepseek-chat","messages":[{{"role":"user","content":"{prompt}"}}]}}'
        ], capture_output=True, text=True)
        log(f"VEND: {agent} - {prompt[:50]}")
        return jsonify({"agent": agent, "result": result.stdout})
    return jsonify({"error": f"Agent {agent} not supported yet"}), 400
if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
FLASK

#!/data/data/com.termux/files/usr/bin/bash
echo " MICO Server + Tunnel Publik"
echo "=============================="
# Matikan proses lama
pkill -f "gunicorn.*mico_server" 2>/dev/null
pkill -f "ssh.*localhost.run" 2>/dev/null
sleep 1
# Jalankan server Flask
cd ~/JDEQ
nohup gunicorn -w 2 -b 0.0.0.0:5000 --chdir api mico_server:app > logs/server.log 2>&1 &
echo "✅ Server berjalan di port 5000"
# Tunggu sebentar
sleep 2
# Buat tunnel publik via localhost.run
echo " Membuka tunnel publik..."
echo "   (URL akan muncul di bawah, bisa diakses dari mana saja)"
echo "   Tekan Ctrl+C untuk menutup tunnel (server tetap berjalan)"
echo ""
ssh -o StrictHostKeyChecking=no -R 80:localhost:5000 localhost.run
START
chmod +x tools/start_mico_server.sh

---
▶️ Cara Pakai
1. Jalankan server + tunnel:
   ```bash
   bash tools/start_mico_server.sh
   ```
   Akan muncul URL seperti https://xxxxx.localhost.run. Salin URL ini.
2. Dari perangkat lain (atau Termux yang sama), akses showcase:
   ```bash
   bash tools/showcase_remote.sh
   ```
   Masukkan URL yang sudah disalin. Anda bisa lihat daftar agen, memanggil agen, dll.
3. URL ini bisa diakses dari mana saja — laptop, ponsel lain, tablet, bahkan dari luar rumah.
---
 Keamanan
· URL publik hanya aktif selama tunnel berjalan.
· API key tetap aman di vault/keys/, tidak pernah dikirim ke luar.
· Tunnel bisa dimatikan kapan saja dengan Ctrl+C di jendela start_mico_server.sh. Server Flask tetap berjalan.
