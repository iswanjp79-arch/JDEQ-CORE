 ALASAN HARUS ADA BERBAGAI JENIS IP ADDRESS
1. IP LOKAL VS IP PUBLIK (IPv4/IPv6)
Keduanya punya tugas berbeda dalam mengirim data:
IP LOKAL
- Apa itu: Alamat unik hanya untuk perangkat di jaringan kecil kamu (misalnya hotspot ponsel atau router rumah). Contoh:  192.168.1.100  (IPv4) atau  fd12:3456:789a::1  (IPv6).
- Mengapa dibutuhkan:
- Agar perangkat di dalam satu jaringan bisa saling berkomunikasi (misalnya laptop kontrol ponsel via Scrcpy, atau ponsel A kirim data ke ponsel B melalui hotspot).
- Mencegah konflik alamat di seluruh dunia – ribuan perangkat bisa punya IP lokal yang sama tapi tidak masalah karena hanya berlaku di jaringanmu sendiri.
- Aman – perangkat dengan IP lokal tidak bisa diakses langsung dari internet luar.
 
IP PUBLIK
 
- Apa itu: Alamat unik untuk seluruh dunia, diberikan oleh provider internet atau operator seluler. Contoh:  202.56.10.23  (IPv4) atau  2001:db8::1  (IPv6).
- Mengapa dibutuhkan:
- Agar perangkat kamu bisa berkomunikasi dengan server di internet (misalnya buka situs web, akses IBM Quantum, atau download aplikasi).
- Sebagai "alamat rumah" kamu di dunia maya – server luar tahu harus mengirim data kemana melalui IP publik ini.
 
2. IPv4 VS IPv6
 
Keduanya adalah versi protokol alamat IP, dengan tujuan sama tapi kapasitas berbeda:
 
IPv4
 
- Apa itu: Versi lama yang sudah ada sejak tahun 1980-an, menggunakan format 4 angka (misalnya  192.168.1.100 ).
- Kapasitas: Hanya bisa menghasilkan sekitar 4 miliar alamat – sudah hampir habis karena banyaknya perangkat yang terhubung ke internet.
- Mengapa masih digunakan: Semua perangkat dan jaringan sudah mendukungnya, jadi masih jadi standar utama.
 
IPv6
 
- Apa itu: Versi baru yang dibuat untuk menggantikan IPv4, menggunakan format kombinasi angka dan huruf (misalnya  2001:db8::a1b2:c3d4 ).
- Kapasitas: Bisa menghasilkan alamat yang tak terbatas (sekitar 340 triliun triliun triliun alamat) – cukup untuk semua perangkat di dunia dan yang akan datang.
- Mengapa dibutuhkan:
- Menyelesaikan masalah kekurangan alamat IPv4.
- Lebih cepat dan aman karena tidak perlu menggunakan teknologi tambahan seperti NAT (Network Address Translation) yang digunakan IPv4.
- Mendukung fitur baru seperti koneksi langsung antar perangkat tanpa melalui server tengah.
 CONTOH KERJA SAMA SEMUA IP ADDRESS
Ketika kamu buka IBM Quantum dari laptop via hotspot ponsel:
1. Laptop punya IP lokal ( 192.168.43.10 ) di jaringan hotspot.
2. Ponsel punya IP lokal ( 192.168.43.1 ) dan IP publik IPv4/IPv6 dari operator.
3. Laptop mengirim permintaan ke IBM Quantum melalui IP lokal ke ponsel.
4. Ponsel meneruskan permintaan menggunakan IP publiknya ke server IBM Quantum.
5. Server IBM Quantum mengirim balasan ke IP publik ponsel, yang kemudian diteruskan ke IP lokal laptop.
 CATATAN UNTUK KESEMPATANMU:
- Saat kamu menggunakan hotspot ponsel, semua perangkat yang tersambung punya IP lokal yang berbeda, tapi berbagi satu IP publik dari ponsel.
- Scrcpy wireless bekerja menggunakan IP lokal saja, jadi tidak perlu menggunakan IP publik atau internet luar – lebih cepat dan hemat kuota!
