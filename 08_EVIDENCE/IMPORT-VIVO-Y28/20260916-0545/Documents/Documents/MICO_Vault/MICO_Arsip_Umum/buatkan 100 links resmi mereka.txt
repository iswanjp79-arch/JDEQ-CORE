## Audit note
Beberapa link di atas adalah **home/docs utama**, bukan selalu halaman API key langsung, karena banyak vendor menaruh key, auth, pricing, dan reference di sub-halaman terpisah. Untuk audit berikutnya, kita bisa pecah lagi per provider: **docs, key, pricing, rate limit, quickstart, curl**. [1][2][15][16]
Kalau kamu mau, langkah berikutnya saya rapikan jadi **CSV audit 100 link** dengan kolom:
**nama, kategori, resmi, legal, free tier, auth page, docs page, rate limit, Termux curl target**.
