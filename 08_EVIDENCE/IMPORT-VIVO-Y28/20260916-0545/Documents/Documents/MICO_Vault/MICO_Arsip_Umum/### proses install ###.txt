## Bundle inti
Bundle ini terdiri dari 3 lapisan:
1. **Dokumen konsep final** untuk dibaca manusia.
2. **ADR bundle** untuk keputusan arsitektur.
3. **registry.json + workflow n8n** untuk eksekusi otomatis oleh agen.  
Dengan format ini, MICO punya satu narasi, satu keputusan, dan satu mesin sinkronisasi. Itu membuat diskusi, keputusan, dan automasi tetap nyambung. [1][2][3]
## 1) Dokumen final PDF-ready
### Judul
**MICO Digital Consciousness Operating Bundle**
### Subjudul
**Dari trigger, registry, ADR, hingga workflow n8n untuk sistem adaptif berlapis**
### Isi ringkas
```md
# MICO Digital Consciousness Operating Bundle
## Tujuan
Dokumen ini menetapkan dasar operasional MICO sebagai sistem adaptif berlapis yang menggunakan trigger, registry, ADR, dan workflow n8n agar semua agen membaca keputusan yang sama.
## Prinsip Dasar
1. Trigger adalah pemicu awal.
2. Registry adalah sumber kebenaran tunggal.
3. ADR menyimpan keputusan penting.
4. n8n menjalankan orkestrasi.
5. Guardrail menjaga konsistensi dan mencegah overwrite liar.
## Alur Sistem
Input → Normalize → Context/Registry Lookup → Reasoning → Execution → Audit → Archive
## Aturan Utama
- Semua keputusan arsitektur harus ditulis sebagai ADR.
- Semua ADR yang diterima dianggap immutable.
- Jika ada keputusan baru, buat ADR baru, jangan edit diam-diam ADR lama.
- Semua agen harus membaca registry sebelum bertindak.
- Output penting harus diverifikasi terhadap SSOT.
## Dampak Operasional
- Mengurangi konflik antar agen.
- Mempermudah audit.
- Menjaga konsistensi keputusan.
- Memudahkan automasi lintas perangkat dan cloud.
## Penutup
Bundle ini dipakai sebagai dokumen dasar MICO agar sistem tetap tumbuh, tetapi tetap terkendali.
```

## 4) Workflow n8n
### Flow
```text
Manual Trigger
↓
Read registry.json
↓
Parse JSON
↓
Filter Accepted ADRs
↓
Select ADR relevan
↓
Send ke AI Agent / next workflow
↓
Log hasil
↓
Update registry jika ada ADR baru
```
### Node ringkas
- **Manual Trigger**: memulai workflow.
- **Read File / HTTP Request**: baca `registry.json`.
- **Code Node**: parse dan normalisasi data.
- **Switch / IF**: pilih ADR aktif.
- **Set Node**: ringkas output.
- **AI Agent Node**: gunakan ADR sebagai konteks.
- **Write File / Log Node**: simpan hasil audit.
### Contoh Code Node
```javascript
const raw = $input.first().json.data || $input.first().json;
const registry = typeof raw === 'string' ? JSON.parse(raw) : raw;
const accepted = registry.adr_index.filter(a => a.status === 'Accepted');
return accepted.map(a => ({ json: a }));
```
## 5) Aturan pakai bundle
1. Simpan dokumen final sebagai `MICO_BUNDLE.md`.
2. Simpan ADR di folder `DECISION_REGISTRY/`.
3. Simpan `registry.json` di root kanonis.
4. Jadikan n8n pembaca utama registry.
5. Jangan overwrite ADR accepted; buat ADR baru bila ada revisi.
