 CONTOH SKRIP TENSORFLOW SEDERHANA YANG BISA JALAN DI VIVO Y28
python
# Import TensorFlow
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense
# Buat model sederhana untuk prediksi
model = Sequential([
    Dense(64, activation='relu', input_shape=(10,)),
    Dense(1, activation='sigmoid')
])
# Kompilasi model
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
# Cetak info model dan versi TensorFlow
print("TensorFlow versi:", tf.__version__)
print("Model berhasil dibuat di Vivo Y28!")
Jalankan skrip ini dengan  python nama_skrip.py  di Termux – pasti bisa jalan!

 PERBAIKI PERINTAHNYA:
Perintah yang benar untuk memasang Python di Termux adalah tanpa tanda garis miring ( / ) di awal:
bash
# Ini yang benar, jalankan aja Pak!
pkg install python
 
Kok error? Karena apakah nulis  /pkg install python  – tanda  /  di awal membuat sistem berpikir kamu mau mengakses file di folder  /pkg , bukan menjalankan perintah  pkg !
 CARA BENAR MEMASANG & CEK PYTHON DI TERMUX:
1. Pasang Python secara resmi dari paket Termux:
bash
pkg update && pkg upgrade -y
pkg install python -y
2. Cek apakah Python sudah terpasang dengan benar:
bash
python --version
Kalau muncul tulisan seperti  Python 3.x.x , berarti berhasil!
 CATATAN UNTUK KAMU:
- Di Termux, perintah untuk mengelola paket selalu dimulai dengan  pkg  (bukan  /pkg ).
- Tanda  /  di awal hanya untuk mengakses folder, bukan untuk menjalankan perintah sistem!
