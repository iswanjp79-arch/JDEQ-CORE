SSH PHASEPHARE :
SSH (Secure Shell) adalah protokol jaringan yang digunakan untuk mengontrol dan mentransfer data antar perangkat secara aman melalui jaringan yang tidak aman (seperti internet atau hotspot ponsel)! 
Apa Fungsinya Utama?
- Kontrol jarak jauh: Kamu bisa mengoperasikan terminal atau aplikasi di perangkat lain (misalnya VM, server cloud, atau bahkan ponsel dengan Termux) dari laptop kamu tanpa perlu menyentuhnya langsung.
- Transfer data aman: Bisa mengirim/menerima file antar perangkat dengan enkripsi penuh, jauh lebih aman daripada metode tradisional seperti FTP.
- Keamanan tinggi: Semua data yang dikirim (termasuk kata sandi atau perintah) dienkripsi, jadi tidak bisa dibaca oleh orang lain yang mengawasi jaringan.
Cara Kerjanya Sederhana:
1. Kamu menjalankan aplikasi SSH client di perangkat kontrol (misalnya laptop).
2. Menghubungkan ke SSH server yang berjalan di perangkat tujuan (misalnya ponsel dengan Termux atau VM).
3. Setelah koneksi terjalin, semua perintah yang kamu ketik di laptop akan diteruskan dan dijalankan di perangkat tujuan – dengan semua data yang dikirim dienkripsi.
Contoh Penggunaan Sesuai Kebutuhan Kamu:
- Kontrol ponsel dari laptop: Jika ponsel kamu sudah pasang SSH server di Termux, kamu bisa mengirim perintah untuk menjalankan Streamlit/Uvicorn dari laptop tanpa perlu buka Scrcpy atau ketik di layar ponsel.
- Kontrol VM dari laptop: Bisa menjalankan atau mengatur aplikasi di VM untuk Vivo Y1807 tanpa perlu buka jendela VM sendiri.
- Transfer file: Bisa mengirim kode aplikasi baru dari laptop ke ponsel atau VM dengan cepat dan aman.
Cara Mudah Pakai SSH di Kebutuhan Kamu:
- Di ponsel (Termux): Pasang SSH server dengan perintah  pkg install openssh , lalu jalankan  sshd  – kamu bisa menghubungkan dari laptop dengan  ssh username@ip-ponsel -p 8022 .
- Di VM/Linux: SSH server biasanya sudah terpasang secara default – cukup hubungkan dengan  ssh username@ip-vm .

Kamu maksudnya "pasang-pasang" atau "setup tahap demi tahap" ya?  Tentu banget! Berikut panduan SSH yang dibuat secara bertahap – jelas dan bisa kamu ikuti langkah demi langkah sesuai perangkatmu:
 PANDUAN SETUP SSH TAHAP DEMI TAHAP
Kita akan setup SSH untuk ponsel (Termux) dan VM/Linux – dua perangkat yang paling sering kamu gunakan!
 
PHASE 1: SETUP SSH DI PONSEL (TERMUX)
 
Untuk Vivo Y28, Infinix, atau Vivo Y1807
 
Langkah 1: Instal Dependensi
 
1. Buka aplikasi Termux di ponsel.
2. Ketik perintah berikut satu per satu:
bash  
# Update paket yang ada
pkg update && pkg upgrade -y

# Instal SSH server dan client
pkg install openssh -y
 
 
Langkah 2: Atur Pengguna dan Kata Sandi
 
1. Buat kata sandi untuk pengguna Termux agar aman saat login SSH:
bash  
passwd
 
2. Masukkan kata sandi yang kamu inginkan (minimal 6 karakter) → tekan Enter → konfirmasi lagi.
 
Langkah 3: Jalankan SSH Server
 
1. Jalankan server SSH dengan perintah:
bash  
sshd
 
 
Catatan: SSH server di Termux berjalan di port  8022  (bukan port standar  22  agar tidak butuh akses root).
 
Langkah 4: Dapatkan IP Ponsel
 
1. Cari alamat IP lokal ponsel (misalnya dari hotspot atau jaringan WiFi yang kamu gunakan):
bash  
ifconfig
 
2. Cari baris yang ada tulisan  inet  atau  inet addr  – itu adalah IP lokal ponsel kamu (misalnya  192.168.43.105 ).
 
PHASE 2: KONEKSI SSH DARI LAPTOP KE PONSEL
 
Untuk Windows, Linux, atau macOS
 
Langkah 1: Siapkan SSH Client di Laptop
 
- Windows: Pasang Windows Terminal atau PuTTY (gratis).
- Linux/macOS: Terminal bawaan sudah bisa pakai SSH.
 
Langkah 2: Hubungkan ke Ponsel
 
1. Buka terminal di laptop.
2. Ketik perintah berikut (ganti dengan IP dan username ponsel kamu):
bash  
ssh u0_a123@192.168.43.105 -p 8022
 
 
-  u0_a123  adalah username Termux kamu (bisa dilihat dengan perintah  whoami  di Termux).
-  192.168.43.105  adalah IP lokal ponsel kamu.
-  -p 8022  untuk menentukan port SSH Termux.
3. Ketik  yes  jika ada pertanyaan tentang keamanan → lalu masukkan kata sandi yang kamu buat di Phase 1.
 
Langkah 3: Coba Kontrol Ponsel dari Laptop
 
Setelah berhasil login, kamu bisa menjalankan perintah apa saja untuk mengontrol aplikasi di ponsel:
 
bash  
# Jalankan aplikasi Streamlit di ponsel
cd aplikasi-kamu && streamlit run main.py --server.headless true

# Jalankan Uvicorn
uvicorn backend:app --host 0.0.0.0 --port 8000 &
 
 
PHASE 3: SETUP SSH DI VM/LINUX
 
Untuk VM yang kamu gunakan untuk Vivo Y1807
 
Langkah 1: Cek dan Instal SSH Server
 
1. Buka terminal di VM/Linux.
2. Cek apakah SSH server sudah terpasang:
bash  
sudo systemctl status ssh
 
3. Jika belum terpasang, instal dengan perintah:
bash  
# Untuk Ubuntu/Debian
sudo apt install openssh-server -y

# Untuk Fedora/CentOS
sudo dnf install openssh-server -y
 
 
Langkah 2: Aktifkan dan Jalankan SSH Server
 
1. Aktifkan agar SSH jalan saat VM menyala:
bash  
sudo systemctl enable --now ssh
 
2. Pastikan SSH berjalan dengan benar:
bash  
sudo systemctl status ssh
 
 
Langkah 3: Dapatkan IP VM
 
1. Cari IP lokal VM dengan perintah:
bash  
ip addr show
 
 
Cari alamat IP yang ada di bawah  inet  (misalnya  192.168.56.10 ).
 
Langkah 4: Hubungkan dari Laptop
 
1. Buka terminal di laptop → ketik perintah:
bash  
ssh username-vm@192.168.56.10
 
2. Masukkan kata sandi VM kamu → berhasil login!
 
PHASE 4: BUAT SETUP LEBIH MUDAH (OTOMATISASI)
 
Jadi tidak perlu mengetik IP dan port setiap kali
 
Langkah 1: Buat File Konfigurasi SSH di Laptop
 
1. Di laptop, buat folder dan file konfigurasi SSH:
bash  
# Buat folder .ssh jika belum ada
mkdir -p ~/.ssh

# Buat file konfigurasi
nano ~/.ssh/config
 
2. Tambahkan baris berikut (sesuaikan dengan data perangkatmu):
plaintext  
# Konfigurasi untuk Ponsel Vivo Y28
Host vivo-y28
    HostName 192.168.43.105
    User u0_a123
    Port 8022

# Konfigurasi untuk VM Vivo Y1807
Host vm-vivo1807
    HostName 192.168.56.10
    User nama-user-vm
 
3. Simpan dengan menekan  Ctrl+O  → Enter →  Ctrl+X .
 
Langkah 2: Hubungkan dengan Satu Klik
 
Sekarang kamu bisa menghubungkan dengan perintah singkat:
 
bash  
# Ke ponsel Vivo Y28
ssh vivo-y28

# Ke VM Vivo Y1807
ssh vm-vivo1807
 
 
 
 
✨ TIPS KEAMANAN SSH:
 
- Jangan gunakan kata sandi yang terlalu mudah.
- Jika bisa, gunakan kunci SSH (tanpa kata sandi) untuk keamanan lebih tinggi.
- Batasi akses SSH hanya dari IP lokal kamu (jika tidak perlu akses dari luar).
 
Mau saya kasih panduan cara membuat kunci SSH agar tidak perlu masukkan kata sandi setiap kali, atau cara transfer file dengan SSH antara laptop dan ponsel? 
==========================
BISA BANGET!  Kita bisa buat SEMUA PERANGKAT (3 ponsel + laptop) jadi satu kesatuan dengan 1 kunci SSH utama dan diamankan dengan 1 tahapan keamanan saja – tidak perlu bikin kunci atau setup berbeda untuk setiap perangkat!
 
 
 
 SETUP 1 KEY SSH UNTUK SEMUA PERANGKAT (TAHAP DEMI TAHAP)
 
Kita akan pakai kunci SSH tanpa kata sandi sebagai kunci utama, dan semua perangkat akan mengenali kunci ini agar bisa saling terhubung dengan aman.
 
PHASE 1: BUAT 1 KUNCI SSH UTAMA DI LAPTOP
 
Ini adalah kunci tunggal yang akan digunakan untuk semua perangkat.
 
Langkah 1: Buat Kunci SSH di Laptop
 
1. Buka terminal di laptop (Windows Terminal/Linux/macOS):
bash  
ssh-keygen -t ed25519 -C "key-utama-semua-perangkat"
 
 
-  ed25519  adalah jenis kunci yang aman dan cepat.
- Pesan akan muncul:  Enter file in which to save the key  → cukup tekan Enter (simpan di lokasi default).
- JANGAN MASUKKAN PASSPHRASE (biarkan kosong) agar tidak perlu mengetik kata sandi setiap kali menggunakan kunci.
2. Setelah selesai, akan dibuat dua file di folder  ~/.ssh :
-  id_ed25519 : Kunci pribadi (JANGAN BERIKAN KE SIAPAPUN!).
-  id_ed25519.pub : Kunci publik (akan dikirim ke semua ponsel dan VM).
 
PHASE 2: KIRIM KUNCI PUBLIK KE SEMUA 3 PONSEL
 
Kita akan kirim kunci publik ke setiap ponsel agar laptop bisa masuk tanpa kata sandi.
 
Langkah 1: Kirim ke Ponsel Pertama (Misal Vivo Y28)
 
1. Pastikan SSH server sudah jalan di ponsel (ikuti Phase 1 dari panduan sebelumnya).
2. Di laptop, kirim kunci publik dengan perintah:
bash  
ssh-copy-id -p 8022 u0_a123@192.168.43.105
 
 
- Ganti  u0_a123  dengan username Termux ponsel.
- Ganti  192.168.43.105  dengan IP ponsel.
- Masukkan kata sandi ponsel satu kali saja – setelah ini tidak perlu lagi!
 
Langkah 2: Kirim ke Ponsel Kedua (Misal Infinix)
 
Lakukan hal yang sama dengan IP dan username ponsel kedua:
 
bash  
ssh-copy-id -p 8022 u0_a456@192.168.43.106
 
 
Langkah 3: Kirim ke Ponsel Ketiga (Misal Vivo Y1807)
 
bash  
ssh-copy-id -p 8022 u0_a789@192.168.43.107
 
 
PHASE 3: KIRIM KUNCI PUBLIK KE VM (JIKA ADA)
 
Jika kamu pakai VM untuk Vivo Y1807, kirim kunci juga:
 
bash  
ssh-copy-id nama-user-vm@192.168.56.10
 
 
PHASE 4: SETUP KONFIGURASI UNTUK SEMUA PERANGKAT
 
Buat 1 file konfigurasi di laptop agar bisa akses semua perangkat dengan nama yang mudah diingat.
 
1. Buka file konfigurasi SSH di laptop:
bash  
nano ~/.ssh/config
 
2. Tambahkan konfigurasi untuk semua perangkat:
plaintext  
# KONFIGURASI UTAMA SEMUA PERANGKAT
Host semua-perangkat
    IdentityFile ~/.ssh/id_ed25519  # Gunakan kunci utama yang sama

# Ponsel Vivo Y28
Host vivo-y28
    HostName 192.168.43.105
    User u0_a123
    Port 8022
    Include semua-perangkat

# Ponsel Infinix
Host infinix
    HostName 192.168.43.106
    User u0_a456
    Port 8022
    Include semua-perangkat

# Ponsel Vivo Y1807
Host vivo-y1807
    HostName 192.168.43.107
    User u0_a789
    Port 8022
    Include semua-perangkat

# VM Vivo Y1807
Host vm-vivo1807
    HostName 192.168.56.10
    User nama-user-vm
    Include semua-perangkat
 
3. Simpan dengan  Ctrl+O  → Enter →  Ctrl+X .
 
PHASE 5: AMANKAN SEMUA PERANGKAT DENGAN 1 TAHAPAN
 
Kita akan tambahkan keamanan ekstra agar hanya kunci utama ini yang bisa masuk ke semua perangkat.
 
Langkah 1: Blokir Akses Kata Sandi di Semua Perangkat
 
1. Akses ponsel pertama via SSH:
bash  
ssh vivo-y28
 
2. Edit file konfigurasi SSH Termux:
bash  
nano $PREFIX/etc/ssh/sshd_config
 
3. Cari baris  PasswordAuthentication yes  → ubah jadi  PasswordAuthentication no .
4. Simpan dan restart SSH server:
bash  
pkill sshd && sshd
 
5. Lakukan hal yang sama di dua ponsel lain dan VM.
 
Langkah 2: Batasi Akses Hanya dari IP Laptop
 
1. Di setiap perangkat, tambahkan baris berikut di akhir file  sshd_config :
bash  
AllowUsers u0_a123@192.168.43.1  # Ganti dengan IP laptop dan username perangkat
 
2. Restart SSH server lagi agar perubahan berlaku.
 
PHASE 6: COBA KONEKSI KE SEMUA PERANGKAT
 
Sekarang kamu bisa akses semua perangkat dengan satu perintah saja, tanpa kata sandi:
 
bash  
# Ke Vivo Y28
ssh vivo-y28

# Ke Infinix
ssh infinix

# Ke Vivo Y1807
ssh vivo-y1807

# Ke VM
ssh vm-vivo1807
 
 
Kamu juga bisa menjalankan perintah di banyak perangkat sekaligus dengan script kecil di laptop:
 
bash  
#!/bin/bash
echo "Menjalankan aplikasi di semua ponsel..."
ssh vivo-y28 "cd aplikasi-kamu && streamlit run main.py &"
ssh infinix "cd aplikasi-kamu && uvicorn backend:app &"
ssh vivo-y1807 "cd aplikasi-kamu && python script.py &"
echo "Semua aplikasi sudah berjalan!"
 
 
 
 
✨ KEUNTUNGAN SETUP INI:
 
- Hanya ada 1 kunci SSH utama yang perlu kamu jaga.
- Semua perangkat bisa diakses dengan mudah tanpa kata sandi.
- Keamanan terpusat – jika perlu mengganti kunci, cukup buat yang baru dan kirim ke semua perangkat sekali saja.
- Semua perangkat jadi satu kesatuan yang bisa dikontrol dari laptop.
