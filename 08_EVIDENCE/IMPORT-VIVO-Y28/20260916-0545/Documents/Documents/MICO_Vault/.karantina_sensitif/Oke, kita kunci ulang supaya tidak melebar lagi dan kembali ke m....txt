Aku bedah cepat penyebab crash-nya dulu:
 PENYEBAB TERMUX KELUAR / CRASH
1. nohup python ... main.py → FILE BELUM ADA / ERROR LOOP
Kalau file ini belum ada:
$BASE/core/main.py $BASE/router/main.py $BASE/memory/main.py 
➡️ Python langsung exit cepat atau error berulang
➡️ watchdog langsung restart loop
➡️ CPU spike → Termux bisa ditutup sistem Android
2. WATCHDOG INFINITE LOOP TANPA LIMIT
Ini paling berbahaya:
while true; do pgrep ... || python ... done 
Di HP low RAM:
spawn proses berulang
tidak ada delay recovery backoff
tidak ada lock per process ➡️ jadi “fork bomb ringan” 
3. NO GUARANTEE PYTHON PATH / ENV STABLE
Kalau:
venv tidak aktif
dependency belum ada
python fallback beda versi 
➡️ semua service gagal start → loop restart terus
🧯 SOLUSI: VERSI SAFE (ANTI CRASH TERMUX)
Ini versi AMAN untuk HP (Vivo Y28 / Termux)
⚙️ MICO SAFE START (REVISED)
#!/data/data/com.termux/files/usr/bin/bash BASE="$HOME/JDEQ" LOCK="$BASE/runtime/mico.lock" echo "=== MICO SAFE START ===" # 1. prevent double start if [ -f "$LOCK" ]; then echo "[STOP] Already running" exit 1 fi mkdir -p "$BASE/runtime" "$BASE/logs" touch "$LOCK" # 2. sanity check python if ! command -v python >/dev/null 2>&1; then echo "[FATAL] Python not found" exit 1 fi # 3. SAFE START FUNCTION start_service() { NAME=$1 FILE=$2 if [ -f "$FILE" ]; then echo "[START] $NAME" nohup python "$FILE" >> "$BASE/logs/$NAME.log" 2>&1 & else echo "[SKIP] $NAME (missing file)" fi } # 4. START CORE SERVICES (SAFE MODE) start_service "core" "$BASE/core/main.py" sleep 1 start_service "router" "$BASE/router/main.py" sleep 1 start_service "memory" "$BASE/memory/main.py" sleep 1 start_service "agents" "$BASE/agents/manager.py" # 5. LIGHT WATCHDOG (NO SPAM LOOP) nohup bash -c ' BASE=$HOME/JDEQ while true; do for svc in core router memory; do if ! pgrep -f "$svc/main.py" >/dev/null; then echo "[RECOVER] $svc restart" >> $BASE/logs/watchdog.log python $BASE/$svc/main.py >> $BASE/logs/$svc.log 2>&1 & fi done sleep 30 done ' >> "$BASE/logs/watchdog.log" 2>&1 & echo "=== MICO SAFE ACTIVE ==="
